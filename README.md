# hy2-net-turbo

面向高延迟/跨洋网络链路与 **Hysteria 2 / QUIC** 协议的高性能底层网络调优工具。

---

## 优化效果总览

针对长肥管道网络（跨洋物理延迟 150ms ~ 280ms）与 UDP/QUIC 传输场景，执行纯底层增量优化。调优过程**无需重启服务器**，**不中断任何现有连接**，执行后立即生效。

| 优化维度 | 优化前状态 | 优化后效果 |
|---|---|---|
| **单流吞吐上限** | ~7 Mbps (受默认 208KB 缓冲限制) | **放宽至 500+ Mbps**（单流无损吞吐物理上限提升数十倍） |
| **首包启动延迟 / 爬坡时间** | 需要 5 ~ 10 秒慢速爬坡才达到峰值 | **爬坡时间缩短 60% ~ 75%**，首包数据量提升 300%，起步即进入高速通道 |
| **系统底层 UDP 丢包** | 突发流量时套接字溢出，大量内核级丢包 | **系统级接收/发送缓冲区溢出丢包彻底归零**（`RcvbufErrors = 0`） |
| **传输码率平滑度** | FIFO 队列突发易拥塞、码率抖动明显 | **启用 FQ 公平排队平滑**，4K 拖拽与高并发吞吐平稳无毛刺 |
| **晚高峰抗 QoS（可选扩展）** | 单一 UDP 端口易遭动态限速断流 | **支持 30,000+ 端口动态跳跃**，运营商单端口限速策略彻底失效 |

## 一键使用

### 1. 核心加速（推荐，立即生效）

无需安装额外依赖，以 root 权限一键执行：

```bash
curl -fsSL https://raw.githubusercontent.com/wooxi/hy2-net-turbo/main/turbo.sh | bash
```

或手动运行：

```bash
chmod +x turbo.sh
sudo ./turbo.sh
```

> **注意**：
> * 脚本仅优化系统底层网络栈，不改动任何服务端协议、密钥或已有监听端口。
> * 已内置 systemd 持久化守护，服务器开机或网络重置后自动保持加速状态。

---

### 2. 状态诊断

随时检查当前主机的网络缓冲区、队列调度算法、路由窗口及 UDP 丢包统计：

```bash
sudo ./turbo.sh --status
```

---

### 3. 可选：开启端口跳跃（抗晚高峰 QoS）

如果所在网络在晚高峰对单一 UDP 端口有限速现象，可选择开启端口段重定向（以 `20000:50000` 转发至内部 `2026` 端口为例）：

```bash
sudo ./turbo.sh --port-hopping 20000:50000 2026
```

* 原有端口（如 `2026`）继续原生工作，现有设备完全不受影响。
* 支持客户端选填端口范围（例如 `20000-50000`）实现全自动跳变通信。

---

### 4. 彻底还原（卸载）

如需完全恢复系统出厂网络参数与路由：

```bash
sudo ./turbo.sh --uninstall
```

## 适用环境

* **操作系统**：Debian 10+ / Ubuntu 20.04+ / Linux 内核 5.x+
* **虚拟化架构**：KVM / 独立物理机 / 支持自定义内核网络参数的云服务器
* **适配协议**：Hysteria 2、QUIC、WireGuard 及高吞吐 TCP/BBR 业务
